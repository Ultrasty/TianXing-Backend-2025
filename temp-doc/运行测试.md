# 天行气象预测平台 - 项目组 Git 协作与 Windows 本地测试指南

本指南专为**基于 Git 远程仓库协作**的团队成员定制。成员通过 Git 拉取最新代码后，即可在各自的 **Windows 本地电脑**上快速启动前后端进行功能测试。

---

## 1. 团队 Git 拉取与环境说明

项目组所有最新代码（包含密码加密组件、JWT 鉴权拦截器、自动测试配置等）均已同步提交至 Git 远程仓库。

### 1.1 拉取最新代码
小组成员在各自本地终端运行：
```bash
# 在天行后端与前端仓库目录下分别拉取
git pull
```

---

## 2. 后端测试启动方案 (TianXing-Backend-2026 / demo_backend)

为适应项目组成员不同的本地环境，后端提供 **H2 零数据库依赖模式** 与 **MySQL 本地数据库模式** 两种启动方式。

### 🌟 方案 A：没装 MySQL 的小组成员（开箱即用极速版 ⭐ 最推荐）
如果成员电脑**未安装任何数据库软件**，无需进行任何数据库配置，在 `demo_backend` 目录下直接运行：

#### Windows CMD / PowerShell 命令：
```cmd
.\mvnw.cmd spring-boot:run -Dspring.profiles.active=h2
```
*(说明：启动时内存库会在内存中**自动建表并自动注入 `admin` / `admin123` 初始账号**，双击或一条命令即跑！)*

---

### 方案 B：已安装 MySQL 的小组成员（MySQL 本地库模式）

如果成员本地电脑已安装 MySQL 数据库：

#### 步骤 1：导入初始化 SQL
在 PowerShell 中运行一条命令导入脚本（仅需执行一次）：
```powershell
Get-Content src\main\resources\sys_user.sql | mysql -u root -p web
```

#### 步骤 2：带密码启动后端
在 CMD 命令行中运行：
```cmd
set DB_PASSWORD=成员本地的MySQL密码&& .\mvnw.cmd spring-boot:run
```

## 3. 前端测试启动方案 (TianXing-Frontend-2026)

### 3.1 前端启动步骤
在 `TianXing-Frontend-2026` 目录下运行：
```bash
# 安装依赖 (仅首次需要)
pnpm install

# 启动开发服务器
pnpm dev
```

### 3.2 智能配置说明 (开箱即用)
项目前端已配置**智能端口自动兜底**：小组成员拉取代码后**无需手动创建或配置 `.env.local` 文件**，启动后会自动智能连接本地 `http://localhost:8888` 后端服务。
*(可选：如需覆盖为其他自定义端口，可在前端根目录新建 `.env.local` 并配置 `VITE_API_PREFIX=http://localhost:自定义端口`)*

## 4. 管理后台测试账号与功能校验

1. 打开浏览器访问后台登录页：
   **`http://localhost:5173/#/admin/login`**
2. 使用默认管理员凭据登录：
   - **默认管理员账号**：`admin`
   - **默认管理员密码**：`admin123`
3. 校验项：
   - 输入错误密码，校验是否弹出提示“用户名或密码错误”。
   - 输入正确密码，校验是否成功跳转至后台看板 `http://localhost:5173/#/admin/dashboard`。
   - 点击“退出登录”后，在地址栏强制输入后台看板网址，校验路由守卫是否成功拦截重定向至登录页。

---

## 5. 技术架构摘要 (供团队技术交流)

- **密码加密算法**：**BCrypt Password Hash**（加盐散列，防彩虹表攻击）
- **会话认证机制**：**Stateless JWT Token**（基于 Header `Authorization: Bearer <Token>`）
- **异常拦截响应**：401 未认证与 403 越权统一返回 JSON 格式结果。
